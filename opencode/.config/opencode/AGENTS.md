# Agents Instructions 

## Output Directory 

- Tous les fichiers générés doivent être sauvegardés dans le répertoire /root/output dans sous-répertoire portant la date du jour sous la forme AAAAMMMJJ
- Exemple, si nous sommes le 3 avril 2026, stockes les productions de fichiers dans le répertoire /root/output/20260403 
- Créer le répertoire s'il n'existe pas 

## Règles générales

- Toujours vérifier que le répertoire /root/output existe avant d'écrire un fichier 
- Utiliser des chemins absolus pour les sauvegardes
